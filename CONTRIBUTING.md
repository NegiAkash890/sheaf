# Helping with Sheaf

The source code is private for now and goes public when this repository reaches 100 stars, so pull requests are not open yet. Here is how you can help today:

- **Use it on a real folder** and tell us what happened. Sheaf needs testing on libraries the author does not have.
- **Report problems** with a [bug report](../../issues/new?template=bug_report.yml). Please describe files instead of attaching them.
- **Share grouping feedback** when collections or names are wrong. It is the most useful input for improving quality.
- **Suggest features** with a [feature request](../../issues/new?template=feature_request.yml). The [roadmap](ROADMAP.md) shows what is already planned.
- **Star the repository.** At 100 stars the source goes public.
