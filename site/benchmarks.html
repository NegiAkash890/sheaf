Model benchmarks

Current defaults (21 November 2026): EmbeddingGemma 2 (270M) for search and Granite 3.3 2B in a compact build for naming. On the 41-question search test they put the right file first 39 times and in the top three every time; grouping F1 on the 64-file test folder is 0.87, and 98% of files graded a strong fit are in the right collection. The tables below are the earlier comparison runs, kept for reference.

What the columns mean

  • Read 20 files: extract text and embed every file. Depends on the embedding model only.
  • Group and name: find relationships, form groups, and have the reasoning model name each group (one call per group).
  • Suggest file names: one short reasoning call per grouped file.
  • Grouping F1: the sample files were labelled by hand into seven themes. For every pair of files we check whether Sheaf put them together when the labels say they belong together. 1.0 is a perfect match. Grouping depends on the embedding model, not the reasoning model.
  • Search: eight plain-language questions, each with one correct file. The score is how many returned that file first.

Caveats

  • One run per configuration on one machine, with 20 short English text files. Treat differences of a few seconds or a few points of F1 as noise.
  • Models were loaded before timing started, so first-use load time is not included.
  • Reproduce with python3 bench/run.py "label|chat model|embedding model". The hand labels are in bench/truth.json.
