Installing Sheaf

1. Download and verify

Download Sheaf-<version>-arm64.dmg and its .sha256 file from the Releases page, then check the download:

cd ~/Downloads
shasum -a 256 -c Sheaf-<version>-arm64.dmg.sha256

It must print OK.

2. Install

Open the DMG and drag Sheaf to Applications.

3. First launch (important)

Sheaf releases are currently not signed with an Apple Developer ID and not notarised. macOS Gatekeeper therefore blocks the first launch. This is expected, and Sheaf does not ask you to switch Gatekeeper off.

  • Open Sheaf once. macOS says it cannot be opened. Choose Done.
  • Open System Settings > Privacy & Security, scroll to Security, and choose Open Anyway next to the Sheaf message. Confirm with your password.

Good to know:

  • The Open Anyway button only appears after you have tried to open Sheaf once. If you do not see it, open Sheaf again, then go back to Privacy & Security and scroll down. It stays available for about an hour.
  • On current macOS versions, right-click > Open no longer gets around this. Use Open Anyway as above.
  • After you choose Open Anyway, macOS asks once more: choose Open, then enter your password or use Touch ID.
  • The message is about Sheaf not being signed yet. It is not a malware finding. If you are unsure, do not continue: check the download against the checksum in section 1 first.

You only do this once per version. Check the download against the published SHA-256 checksum first (section 1 above), so you know it is the file that was released.

4. Set up the local AI

Sheaf uses Ollama, a free model runner, to run the models on your Mac. Sheaf can install it for you:

  • In Sheaf's setup, choose Install Ollama. Sheaf downloads it once (about 185 MB) from Ollama's official release page on GitHub, checks it against the checksum published there and against Ollama's developer signature, and keeps it in its own folder. This is the only time Sheaf uses the internet, apart from the model downloads Ollama does itself. If you would rather do it yourself, install Ollama from ollama.com/download or with brew install ollama; Sheaf finds either one. Do this before the models step: the download needs Ollama running.
  • Open Sheaf. The first-launch setup finds Ollama on its own. If Ollama is installed but not running, choose Start It.
  • Pick the size of the writing AI: Bigger (Recommended) gives more specific collection names (about 2.4 GB in all, once); Light (Quicker) is smaller and faster (about 1.6 GB in all). Then choose Set Up. Sheaf downloads what it needs and shows progress. It then works offline. You can switch size any time in Settings.

5. Use it

Choose Add Folder… and let Sheaf read it. Look through Collections and Graph, then open Organise to see a proposed plan. Nothing moves until you choose Move Files, and History > Undo puts everything back.

macOS will ask for permission the first time Sheaf reads Desktop, Documents or Downloads.

Updating

Download the new DMG and replace the app. If a release enables in-app updates, Sheaf > Check for Updates… offers them; updates are never installed without your say-so.

Uninstalling

Delete Sheaf.app and ~/Library/Application Support/Sheaf (this also removes the copy of Ollama that Install Ollama set up). Your files are untouched. The downloaded AI lives in ~/.ollama: delete that folder to remove it.

Troubleshooting

macOS says Sheaf cannot be opened

Expected for unsigned builds. Open Sheaf once and choose Done. Then open System Settings > Privacy & Security, scroll to Security, choose Open Anyway next to the Sheaf message and confirm with your password. See Installing Sheaf.

Sheaf says Ollama is not running

Choose Start Ollama in Settings (or Start It in first-launch setup). If Ollama is not installed yet, get it from ollama.com/download. In Terminal, this starts it as a background service:

brew services start ollama

To check that it answers, run curl http://127.0.0.1:11434/api/tags. It should print a list of installed models. Then choose Check Again in Sheaf.

The AI download is missing or incomplete

Sheaf offers Download Both in setup and Download in Settings. Check your connection, run it again, then choose Check Again.

Sheaf cannot read my Desktop, Documents or Downloads

macOS asks for permission the first time. If you declined, choose Open Privacy Settings in Sheaf, or open System Settings > Privacy & Security > Files & Folders and allow Sheaf to access the folder.

Reading is slow

On a Mac with less memory, first-time reading takes 6 to 22 seconds per short document, and longer when other apps are busy. Close memory-heavy apps, leave the Mac plugged in, and let the first run finish: later runs read only what changed. The reasoning model is released from memory three minutes after it was last used. You can press Stop at any time and continue later.

Collections look wrong

  • Untick any move you disagree with before applying a plan.
  • Rename a collection, or drag a file into another one.
  • Orange marks in Collections show files that may be in the wrong group.
  • Changing the embedding model re-reads every file and can change the groups.
  • Open a Grouping or naming feedback issue so the grouping can be improved. Describe the files instead of attaching them.

I want to undo a move

Open History and choose Undo for that change. Files you removed are in the Trash.

Start again from scratch

Use Rescan Everything… to read all files again. For a full reset, quit Sheaf and delete ~/Library/Application Support/Sheaf. Your files are not affected.

What to include in a bug report

  • What you did, what you expected and what happened.
  • The Sheaf version.
  • Your Mac model and macOS version (sw_vers in Terminal).
  • Whether you chose Bigger or Light.
  • Roughly how many files were in the folder.

Please do not attach personal files. Describe them instead. Open an issue from the issue page.

The AI Sheaf uses

Sheaf runs two small AI models on your Mac, through a free model runner that setup installs for you. Nothing is sent anywhere.

SizeDownloadWhat you get
Bigger (Recommended)about 2.4 GB, onceMore specific collection names. A little slower and uses more memory.
Light (Quicker)about 1.6 GB, onceThe same jobs with a smaller model. Collection names are more general.

You choose Bigger or Light in setup and can switch in Settings, where the other size downloads on demand. Sheaf does not ship the models; setup downloads them and you accept their licences.

Memory on smaller Macs

  • One file is processed at a time; nothing is batched across files.
  • The models are released from memory a few minutes after last use.
  • Both models are small enough to be loaded together (about 2.5 GB with Light, 3 GB with Bigger), leaving room for macOS and other apps.

Measured on an Apple Silicon Mac: 6 to 22 seconds per short text document for first-time understanding, depending on what else the Mac is doing. After that only new or changed files are read again.
