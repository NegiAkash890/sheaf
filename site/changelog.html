Changelog

All notable changes are recorded here. Format follows Keep a Changelog; versions follow SemVer.

[0.1.1] - unreleased

Added

  • Search by people, places, things and ideas found inside your files, with the collection a result belongs to shown above the results.
  • Hybrid search: meaning and exact words together, file names that contain every word typed rank high, PDF results open on the matching page.
  • Plain-language filters ("pkg files", "pdfs from last week about rent"), read without a model.
  • A fit score for every file in a collection, from how it links to the rest (no model). Loose fits are marked; clear misfits are left out.
  • Collections recognise the kind of paper (CV, certificate, marksheet, ID, offer letter, receipt), so a CV is not grouped with the certificates it lists. Broad or Detailed sorting in Settings.
  • Collection names never use a person's name.
  • A sample folder of invented files ships with Sheaf: try every screen, with a step-by-step guide, while the models download.
  • The progress card links each finished step to its screen (Search, Graph, Collections) as reading carries on.
  • Highlight one kind of file in Collections and the Graph; quick panel from any app; Overview with people, places, things and ideas.
  • Report a Problem: a GitHub issue filled in for you to read and send, with paths blanked out.
  • Collection edits are kept in History and can be undone with Command-Z after the note has gone.

Changed

  • Default models: EmbeddingGemma 2 (270M) for search, Granite 3.3 2B (compact build) for naming. About 1.6 GB in total.
  • Search: 39 of 41 test questions answer first time (was 38), all in the top three.
  • Grouping F1 on the 64-file test folder: 0.83 (was 0.65).
  • Organise scrolls smoothly with hundreds of planned moves.
  • New name: Sheaf. The app, command-line tool (sheaf-cli), bundle identifier, website and documentation all use the new name.
  • On first launch Sheaf copies a library made by an earlier version (in Application Support) into its own folder and leaves the old one untouched.
  • Environment variables now begin SHEAF_.

[0.1.0] - unreleased

First development milestone. Built and tested on Apple Silicon, macOS 26.

Added

  • Folder selection, read-only incremental scanning, SQLite store, file browser.
  • Local understanding with Ollama: embeddings, structured summaries, document types, topics and entities; on-device named-entity recognition and OCR.
  • Natural-language search over passages, with the reason for each match.
  • Relationship discovery with a library-calibrated similarity threshold and shared-name links; explanations for every relationship.
  • Content-derived groups named by the local model; interactive graph view.
  • Organisation proposals with per-move approval and optional clearer file names.
  • Journaled, validated, undoable file moves; automatic rollback on failure; recovery after an interrupted run.
  • Command-line twin (sheaf-cli), DMG packaging script, optional Sparkle updates.

Known limitations

  • Releases are ad-hoc signed and not notarised.
  • Folder structures are one level deep.
  • Tested on small libraries (tens of files). Large libraries (thousands of files) are untested.
